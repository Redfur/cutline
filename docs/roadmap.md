# План

Пять этапов. Каждый заканчивается состоянием, в котором инструментом можно пользоваться — ни один не оставляет проект в нерабочем виде.

---

## Этап 1. Модель и рендерер

Внешне не меняется ничего, но макет перестаёт быть прошитым в коде.

- [x] Каркас проекта: Vite, React, TypeScript
- [x] Типы модели документа из `docs/document-model.md`
- [x] `render(doc, record, opts) → SVG` — чистая функция без обращений к DOM
- [x] Измерение текста: единый модуль для превью и экспорта
- [x] Автоподгонка: режимы `shrink`, `clip`, `wrap`
- [x] Макет бейджа из прототипа, описанный документом, а не кодом
- [x] Экспорт SVG и PNG
- [x] Сохранение и загрузка проекта файлом

**Готово, когда** текущий бейдж собирается из JSON и экспортируется так же, как в прототипе.

---

## Этап 2. Редактирование

- [x] Холст: масштаб, панорамирование, линейки, показ вылета и безопасного поля
- [x] Выделение элемента, рамка с маркерами
- [x] Перетаскивание и изменение размера
- [x] Инспектор свойств справа, разный для каждого типа
- [x] Добавление и удаление элементов, панель инструментов (rect/ellipse/line/text/image)
- [x] Список слоёв: порядок, переименование, замок, видимость
- [x] **История изменений**: undo/redo, группировка мелких шагов
- [x] Привязки: к другим элементам, к центру, к полям
- [x] Горячие клавиши: удаление, дублирование, сдвиг стрелками, отмена

**Готово, когда** можно собрать макет с нуля, ни разу не заглянув в JSON.

---

## Этап 3. Данные

- [ ] Таблица записей: добавление, удаление, редактирование ячеек
- [ ] Колонки: создание, переименование, удаление
- [ ] Импорт CSV с сопоставлением колонок
- [ ] Экспорт CSV
- [ ] Подстановка плейсхолдеров в текст и в изображения
- [ ] Сетка миниатюр: все записи разом
- [ ] Подсветка проблем: переполнение, пустое обязательное поле
- [ ] Переключение предпросмотра между записями

**Готово, когда** двадцать пять карточек видно одним экраном и понятно, где что сломалось.

---

## Этап 4. Печать

- [ ] PDF через pdf-lib: вылеты, TrimBox и BleedBox
- [ ] Перевод текста в кривые
- [ ] Метки реза
- [ ] Спуск полос: несколько карточек на лист, выбор формата листа
- [ ] Вариант с полями для домашнего принтера
- [ ] Двусторонняя печать: зеркальный оборот
- [ ] Пакетный экспорт: все записи одним PDF

**Готово, когда** файл можно отправить в типографию без правок.

---

## Этап 5. Публикация

- [ ] Пресеты холста: A6, A7, визитка, бейдж, произвольный
- [ ] Готовые шаблоны, с которых можно стартовать
- [ ] Онбординг: что это и с чего начать
- [ ] Мобильная версия — только просмотр, с честным предупреждением
- [ ] Сборка и деплой на статический хостинг
- [ ] README с примерами и скриншотами

**Готово, когда** незнакомый человек открывает ссылку и делает свой бейдж, ничего не спрашивая.

## Что отложено сознательно

Группы элементов, кривые Безье, тени и эффекты, совместное редактирование, аккаунты, облако, версионирование, мобильное редактирование.
