# Спецификация интерфейса

Пять экранов и общая оболочка. Проектировать по одному, в порядке ниже. К каждому приложен готовый бриф для Claude Design.

---

## Общая оболочка

Присутствует на всех экранах, кроме стартового.

**Верхняя панель, слева направо:**
- логотип и название проекта
- имя документа, редактируется по клику
- индикатор сохранения: «Сохранено» / «Сохраняем…»
- переключатель режимов: **Дизайн** | **Данные**
- справа: кнопка «Экспорт», меню с загрузкой и сохранением файла

Высота 48 px. Переключатель режимов — по центру, это главная навигация продукта.

**Чего в оболочке нет:** боковой навигации, хлебных крошек, уведомлений, аватарки. Режимов всего два, любая дополнительная навигация будет шумом.

## Экран 1. Режим дизайна

Самый сложный. Проектировать первым, но реализовывать вторым — сначала данные.

### Раскладка

Три колонки: слои слева (220 px), холст в центре (тянется), инспектор справа (280 px). Панель инструментов — вертикальной полосой слева от холста, 48 px.

### Панель инструментов

Иконки сверху вниз: выделение, текст, прямоугольник, эллипс, линия, изображение. Активный инструмент подсвечен. Внизу отдельной группой — масштаб: минус, значение в процентах, плюс, «по размеру окна».

### Холст

Карточка по центру серого фона. Видны три границы:
- **обрез** — сплошная тонкая линия, главная
- **вылет** — пунктир снаружи, 3 мм
- **безопасное поле** — пунктир внутри, светлее

Линейки по верху и левому краю, в миллиметрах. При перетаскивании элемента на линейках подсвечивается его диапазон.

Направляющие привязки появляются при перетаскивании: когда край или центр элемента совпадает с краем или центром другого, возникает тонкая линия акцентного цвета.

### Список слоёв

Строка слоя: иконка типа, имя (правится двойным кликом), иконка замка, иконка видимости. Перетаскивание меняет порядок наложения. Выделенный слой подсвечен, при наведении на строку подсвечивается элемент на холсте.

Сверху строка поиска — нужна, когда элементов больше пятнадцати.

### Инспектор

Содержимое зависит от выделения. Секции разделены тонкими линиями, заголовки мелкие и серые.

**Ничего не выделено — свойства холста:**
размер в мм с пресетами (A6, A7, визитка, произвольный), вылет, безопасное поле, цвет фона.

**Выделен текст:**
- Содержимое: поле ввода, рядом кнопка вставки плейсхолдера — выпадающий список полей данных
- Положение: X, Y, ширина, высота, поворот
- Шрифт: семейство, начертание, кегль, межбуквенный интервал, межстрочный
- Выравнивание: по горизонтали и вертикали, иконками
- Цвет
- **Автоподгонка**: сжимать / обрезать / переносить / не трогать, плюс минимальный кегль для режима сжатия

**Выделена фигура:**
положение, заливка, обводка с толщиной, радиус скругления.

### Состояния, которые обязательно показать

1. **Выделен текстовый элемент** — рамка с восемью маркерами, инспектор заполнен
2. **Ничего не выделено** — инспектор показывает свойства холста
3. **Текст не влез** — элемент обведён предупреждающим цветом, в инспекторе у секции автоподгонки поясняющая строка
4. **Перетаскивание** — видны направляющие привязки и подсветка на линейках
5. **Элемент заблокирован** — маркеры не показываются, поля инспектора неактивны

### Бриф

```
Спроектируй главный экран веб-приложения Cutline — режим дизайна.

ЧТО ЭТО
Конструктор печатных карточек с переменными данными: один макет,
таблица записей, тираж на выходе. Бейджи, карточки гостей, ценники.

КТО ПОЛЬЗУЕТСЯ
Организаторы мероприятий, малый бизнес. Не дизайнеры. Ноутбук,
работа под дедлайном, обычно один раз перед событием.

РАСКЛАДКА
— верхняя панель 48px: логотип, имя документа, индикатор сохранения,
  переключатель «Дизайн | Данные» по центру, справа «Экспорт» и меню
— вертикальная панель инструментов 48px: выделение, текст,
  прямоугольник, эллипс, линия, изображение; внизу — масштаб
— слева 220px: список слоёв (иконка типа, имя, замок, видимость)
— центр: холст с карточкой 105×148 мм на сером фоне, линейки в мм,
  видны линия обреза, вылет пунктиром снаружи, безопасное поле внутри
— справа 280px: инспектор свойств выделенного элемента

ИНСПЕКТОР ДЛЯ ТЕКСТА, СЕКЦИЯМИ
содержимое (с кнопкой вставки плейсхолдера), положение и размер,
шрифт и кегль, выравнивание, цвет, правило автоподгонки

ПОКАЖИ ТРИ СОСТОЯНИЯ
1. Выделен текст: рамка с маркерами, инспектор заполнен
2. Ничего не выделено: инспектор показывает свойства холста
3. Текст не влез: элемент подсвечен предупреждением

СТИЛЬ
Рабочий инструмент. Плотная информативная вёрстка. Интерфейс тихий
и серый, чтобы не спорить с макетом на холсте; цвет только
у акцентов и предупреждений. Светлая тема.

НЕ НАДО
Иллюстраций, градиентов, лишних скруглений, аватарок, уведомлений.
```

## Экран 2. Режим данных

Проще в проектировании и важнее по смыслу — ради него продукт и существует.

### Раскладка

Две части по вертикали: таблица сверху (примерно 55% высоты), сетка миниатюр снизу. Разделитель тянется мышью.

### Таблица

Обычная сетка: строки — записи, колонки — поля. Первая колонка узкая, с номером и кнопкой удаления при наведении.

Заголовок колонки: имя поля, меню с переименованием, изменением ключа и удалением. Справа от последней колонки — кнопка добавления поля.

Под таблицей — кнопка добавления записи, рядом «Импорт CSV».

Ячейка с проблемой (пусто в поле, которое используется в макете; текст, который не влезет) отмечается тонкой полосой слева и иконкой.

### Сетка миниатюр

Карточки по 120 px в ширину, в несколько рядов. Под каждой — значение первого текстового поля, обычно имя.

Миниатюра с проблемой обведена предупреждающим цветом. Клик по миниатюре выделяет соответствующую строку таблицы и наоборот.

Сверху полоса с фильтром: «Все» / «С проблемами», счётчик записей.

### Состояния

1. **Пусто** — нет ни одной записи: по центру приглашение добавить запись или импортировать CSV
2. **Заполнено** — двадцать пять записей, видна сетка миниатюр
3. **Есть проблемы** — три карточки подсвечены, фильтр показывает счётчик
4. **Импорт CSV** — диалог сопоставления колонок файла с полями документа

### Бриф

```
Спроектируй экран «Данные» приложения Cutline (описание продукта
и стиль — как в предыдущем брифе).

РАСКЛАДКА
— сверху таблица записей: строки — люди, колонки — поля документа
  (Имя, Должность, Отдел, Дата). Заголовки колонок с меню,
  справа кнопка добавления поля. Снизу кнопки «Добавить запись»
  и «Импорт CSV»
— снизу сетка миниатюр карточек, по 120px, несколько рядов,
  под каждой имя. Сверху сетки — фильтр «Все / С проблемами»
  и счётчик записей
— горизонтальный разделитель между ними тянется мышью

ПОКАЖИ ТРИ СОСТОЯНИЯ
1. Заполнено: 25 записей, сетка миниатюр
2. Пусто: приглашение добавить запись или импортировать CSV
3. Есть проблемы: 3 миниатюры подсвечены предупреждением,
   в таблице соответствующие ячейки помечены
```

## Экран 3. Экспорт

Панель, выезжающая справа, а не отдельная страница. Ширина 380 px.

**Содержимое:**
- Что экспортируем: все записи / выбранные / только макет без данных
- Формат: PDF, SVG, PNG
- Для PDF: вылеты, метки реза, текст в кривых, разрешение
- Спуск полос: по одной карточке на страницу / несколько на лист, с выбором формата листа и вариантом «с полями для домашнего принтера»
- Двусторонняя печать: оборот тем же файлом, зеркально
- Внизу: предпросмотр первой страницы и кнопка «Экспортировать»

Настроек много, поэтому секции сворачиваются, а часто используемые открыты по умолчанию.

### Бриф

```
Спроектируй панель экспорта приложения Cutline. Выезжает справа,
ширина 380px, поверх основного экрана с затемнением.

СЕКЦИИ
— что экспортируем: все записи / выбранные / только макет
— формат: PDF / SVG / PNG
— параметры PDF: вылет, метки реза, текст в кривых, разрешение
— спуск полос: одна на страницу / несколько на лист,
  формат листа, вариант с полями для домашнего принтера
— двусторонняя печать
— внизу предпросмотр первой страницы и кнопка «Экспортировать»

Настроек много: секции сворачиваемые, часто используемые раскрыты.
```

## Экран 4. Стартовый

Что видит человек, открыв ссылку впервые. Без него продукт непонятен.

**Содержимое:**
- Название и одна строка о том, что это
- Три-четыре шаблона карточками: бейдж, карточка гостя, ценник, сертификат. Каждый с превью
- Кнопка «Пустой документ» с выбором формата
- Ссылка «Открыть файл»
- Если есть недавние документы — список снизу

Никакого маркетингового лендинга: человек уже пришёл, ему нужно начать.

### Бриф

```
Спроектируй стартовый экран приложения Cutline — первое, что видит
человек, открыв ссылку.

СОДЕРЖИМОЕ
— название и одна строка: «Один макет, много карточек»
— четыре шаблона карточками с превью: бейдж мероприятия,
  карточка гостя, ценник, сертификат
— кнопка «Пустой документ» с выбором формата
— ссылка «Открыть файл»
— снизу список недавних документов (покажи и вариант, когда он пуст)

Это не лендинг, а точка входа в инструмент: без рекламных блоков,
отзывов и призывов к регистрации.
```

## Экран 5. Мобильный просмотр

Редактор с перетаскиванием на телефоне не работает — честнее сделать просмотр.

**Содержимое:** список карточек, открытие одной на весь экран, кнопка «Поделиться». Сверху — строка с пояснением, что редактировать можно только с компьютера.

Низкий приоритет, проектировать последним.

---

## Порядок работы

1. Экран данных — проще, и он определяет суть продукта
2. Экран дизайна — самый сложный, делать на свежую голову
3. Панель экспорта
4. Стартовый экран
5. Мобильный просмотр

После того как экраны устроят, запросить сводку дизайн-системы: палитра с кодами, шкала отступов, размеры шрифтов, высота элементов управления, радиусы. Положить в `docs/design-system.md` и строить компоненты по ней.

## Как итерировать

Общие правки вроде «сделай лучше» дают случайный результат. Работает точечное:

- «инспектор слишком широкий, сделай 260»
- «покажи состояние наведения на строку слоя»
- «убери скругления у полей ввода, инструмент должен выглядеть строже»
- «добавь в шапку таблицы кнопку сортировки»

Если экран получился перегруженным, самый действенный вопрос к себе: **что отсюда можно убрать, не сломав сценарий?** В инструментах для работы плотность полезна, но только когда каждый элемент нужен.
