# Прототип

`badge-editor-v1.html` — рабочая версия на ванильном JS, с которой начался проект.
Открывается двойным кликом, без сборки.

Что оттуда переносится:

- дизайн карточки A6 и её раскладка
- логика автоподгонки текста: уменьшение кегля до минимума, затем обрезка
- измерение строк через canvas для системных шрифтов и через opentype.js для загруженных
- перевод текста в кривые
- вылеты и подход к печатным размерам

Что переписывается: всё остальное. Макет там прошит в коде, редактирования элементов нет.
