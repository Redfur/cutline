# Cutline

Конструктор печатных карточек с переменными данными. Один макет — много записей: бейджи для мероприятия, карточки гостей, номерки на столы, ценники, сертификаты.

## Зачем, если есть Canva и Figma

Общие редакторы отлично рисуют одну карточку и плохо делают двадцать пять разных. Здесь наоборот: рисование ровно такое, чтобы собрать свой макет, зато слияние с данными, защита вёрстки от длинных строк и печатный PDF — из коробки.

Три вещи, которых нет у конкурентов в бесплатном виде:

- **Слияние с данными.** Макет один, записей сколько угодно, подстановка через плейсхолдеры `{{name}}`.
- **Фиксированный размер.** Длинный текст ужимается по кеглю или обрезается по заданному правилу — карточка не меняет габариты никогда.
- **Готовность к типографии.** Вылеты, метки реза, текст в кривых, спуск полос на лист.

## Стек

- React + TypeScript, сборка через Vite
- Zustand для состояния, immer для истории изменений
- Рендеринг в SVG (не canvas) — попадание курсора решается средствами DOM, экспорт совпадает с экраном
- opentype.js для перевода текста в кривые
- pdf-lib для сборки PDF
- Без бэкенда: проект живёт в браузере, сохраняется файлом

## Запуск

```bash
npm install
npm run dev
```

## Структура

```
src/
  model/       схема документа, валидация, миграции
  render/      чистая функция (документ, запись) → SVG
  editor/      холст, инструменты, инспектор, слои
  data/        плейсхолдеры, проблемы записей, CSV — чистые функции без DOM
  export/      SVG, PNG, PDF, спуск на лист
  storage/     автосохранение сессии в IndexedDB (idb-keyval)
docs/
  document-model.md   схема документа
  roadmap.md          этапы и задачи
reference/
  badge-editor-v1.html  рабочий прототип, от которого отталкиваемся
```

## Прототип

В `reference/` лежит рабочая версия на ванильном JS: один файл, жёстко прошитый макет A6, автоподгонка текста, экспорт SVG и PNG, перевод в кривые через загруженный файл шрифта. Дизайн карточки, логика `fit`/`clip` и подход к единицам измерения переносятся оттуда — остальное переписывается.

## Принципиальные решения

**Миллиметры внутри, пиксели только при показе.** Вся геометрия документа в миллиметрах. Иначе накопятся расхождения между экраном и печатью.

**Рендерер — чистая функция.** Ни одного обращения к DOM редактора. Из этого бесплатно получаются превью, сетка миниатюр, экспорт и пакетная генерация.

**Только открытые шрифты в поставке.** JetBrains Mono, IBM Plex, Inter. Системные шрифты вроде Menlo и Consolas распространять нельзя — их пользователь подгружает сам.
